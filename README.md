# 1st ToDo LP

Android向けToDoアプリ「1st ToDo」のランディングページとプライバシーポリシーです。

公開先: [https://todo1.naotnoguchi.com](https://todo1.naotnoguchi.com)

## ページ

- `/` — アプリ紹介
- `/privacy/` — プライバシーポリシー

## 開発

```sh
npm install
npm run dev -- --background
npm run build
```

`main`ブランチへのpushで、GitHub ActionsからGitHub Pagesへデプロイされます。
